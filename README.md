# homebrew-tap

A Homebrew tap for software and tools by me.

## Usage

```
brew tap wassimk/tap
```

## Available Formulae

| Formula | Description |
| --- | --- |
| [`elgato-autolight`](https://github.com/wassimk/elgato-autolight) | Automatically toggle Elgato lights when your Mac camera activates |
| [`elgato-light`](https://github.com/wassimk/elgato-light) | CLI to control Elgato Key Light and Key Light Air devices |
| [`st`](https://github.com/wassimk/st) | Set your status across Slack and GitHub with a single command |
| [`tmignore`](https://github.com/wassimk/tmignore) | Exclude developer dependency directories and arbitrary paths from macOS backups |
| [`zoom-autostatus`](https://github.com/wassimk/zoom-autostatus) | Automatically set your Slack status while you're in a Zoom meeting |

### Install

```
brew install wassimk/tap/elgato-autolight
brew install wassimk/tap/elgato-light
brew install wassimk/tap/st
brew install wassimk/tap/tmignore
brew install wassimk/tap/zoom-autostatus
```
